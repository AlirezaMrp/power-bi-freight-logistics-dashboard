# Global Freight & Shipment Performance Dashboard

An interactive and visually designed Power BI dashboard developed to analyse global freight operations, shipment performance, logistics costs and delivery efficiency across countries and shipment modes.

This project demonstrates how business intelligence and data visualisation can transform raw logistics data into operational insights for decision-making, performance monitoring and supply chain analysis.

---

## Project Overview

The dashboard was created to explore key logistics and freight performance indicators through an intuitive and modern interface. It combines operational KPIs, geographic analysis, shipment trends, and interactive filtering to provide a comprehensive overview of supply chain performance.

The project focuses on:

* Freight cost monitoring
* Shipment value analysis
* Delivery performance evaluation
* Shipment mode comparison
* Geographic distribution of shipments
* Interactive operational analysis

---

## Dashboard Features

### Executive KPI Overview

Track core logistics metrics including:

* Total Freight Cost
* Total Shipment Value
* Average Freight Cost
* On-Time Delivery Percentage

---

### Interactive Filters

Users can dynamically filter the dashboard by:

* Country
* Shipment Mode
* Product Group

---

### Freight Cost Analysis

Analyse freight expenses across different transportation modes such as:

* Air
* Truck
* Ocean
* Air Charter

---

### Delivery Performance Insights

Identify top-performing countries based on on-time delivery performance and operational efficiency.

---

### Global Shipment Map

Visualise shipment value geographically through an interactive world map.

---

### Freight Trend Analysis

Monitor freight cost evolution over time using trend analysis visuals.

---

### Dynamic KPI Selector

An interactive KPI selector allows users to dynamically switch between:

* Freight Cost
* Shipment Value
* Quantity
* On-Time Delivery

---

### Decomposition Tree Analysis

Explore operational drivers behind freight costs through hierarchical breakdowns by:

* Country
* Shipment Mode
* Product Group
